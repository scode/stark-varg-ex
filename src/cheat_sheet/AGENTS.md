# Cheat sheet authoring

Optimize these pages for printing one practical page at a time. The default order is:

1. Title.
2. A short NOTE that scopes the page and calls out that it is not the full manual.
3. The procedure, so the instructions are at the top and less likely to span printed pages.
4. Specs, tools, consumables, intervals, sources, and related resources.

Keep boilerplate out of the procedure. Include the details that matter while doing the job: torque values, orientation
or leveling notes, washers, fill references, and other steps where skipping a detail changes the result.

Do not invent certainty. If a source lists a tool but does not map it to a specific fastener, leave the mapping out
until someone verifies it manually. If a step comes from inference or personal practice rather than Stark documentation,
say that directly.

Use compact prose and numbered steps. Prefer one concise page over a complete rewrite of the manual.
